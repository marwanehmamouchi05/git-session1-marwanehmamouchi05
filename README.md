![Session 1 project banner](assets/project-banner.svg)

**Author:** Marwane Hmamouchi  
**GitHub username:** marwanehmamouchi05  
**Course:** CSC3324, Section 02

This starter-based website demonstrates Git repository setup, logical commits,
selective staging, an About feature branch, merging, and GitHub synchronization.

## Technologies

- HTML for page structure
- CSS for styling
- JavaScript for the status message
- Git and GitHub for version control

## Run locally

Open `index.html` in your browser. No dependencies or build step are needed.

```sh
git clone https://github.com/marwanehmamouchi05/git-session1-marwanehmamouchi05.git
cd git-session1-marwanehmamouchi05
```

## Git workflow

The `feature/about` branch adds an About section and is merged into `main`.
Local settings and ordinary logs are ignored; `important.log` stays tracked.

Reference: [Official Git documentation](https://git-scm.com/doc).
